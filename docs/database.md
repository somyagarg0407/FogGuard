# FogGuard Database Architecture

FogGuard uses SQLite via SQLAlchemy 2.0 ORM for zero-configuration, reliable, file-backed persistence.

Database file: `backend/fogguard.db`

---

## 1. Tables & Schema

### Table: `sensor_readings`
Records incoming high-frequency distance measurements for individual sensors.
- `id` (INTEGER, Primary Key, Auto-increment)
- `sensor_id` (VARCHAR(10), Indexed) — e.g. "S1", "S2"
- `zone` (VARCHAR(50), Indexed) — e.g. "front_left"
- `distance_cm` (FLOAT, Nullable)
- `obstacle_detected` (BOOLEAN)
- `warning_level` (VARCHAR(20), Indexed) — "SAFE", "CAUTION", "WARNING", "CRITICAL", "CLEAR"
- `timestamp` (DATETIME, Indexed, Default: UTC Now)

### Table: `obstacle_events`
Records discrete obstacle appearance events when sensors transition into detected states.
- `id` (INTEGER, Primary Key, Auto-increment)
- `sensor_id` (VARCHAR(10), Indexed)
- `zone` (VARCHAR(50), Indexed)
- `distance_cm` (FLOAT, Not Null)
- `severity` (VARCHAR(20), Indexed)
- `event_type` (VARCHAR(20)) — "DETECTED", "APPROACHING", "CLEARED"
- `timestamp` (DATETIME, Indexed, Default: UTC Now)

### Table: `warning_events`
Records formal alerts generated by the backend Warning Engine with deduplication.
- `id` (INTEGER, Primary Key, Auto-increment)
- `sensor_id` (VARCHAR(10), Indexed)
- `zone` (VARCHAR(50), Indexed)
- `distance_cm` (FLOAT, Nullable)
- `warning_level` (VARCHAR(20), Indexed)
- `warning_message` (VARCHAR(500), Not Null)
- `acknowledged` (BOOLEAN, Indexed, Default: False)
- `timestamp` (DATETIME, Indexed, Default: UTC Now)

### Table: `traffic_signal_events`
Records state transitions of the traffic signal (RED, GREEN, YELLOW).
- `id` (INTEGER, Primary Key, Auto-increment)
- `signal_state` (VARCHAR(10), Indexed)
- `duration_seconds` (INTEGER, Nullable)
- `timestamp` (DATETIME, Indexed, Default: UTC Now)

### Table: `device_status`
Tracks heartbeats and operational health of system components.
- `id` (INTEGER, Primary Key, Auto-increment)
- `device_name` (VARCHAR(50), Unique, Indexed)
- `device_type` (VARCHAR(50), Not Null)
- `connection_status` (VARCHAR(20), Indexed) — "CONNECTED", "SIMULATED", "DISCONNECTED", "UNKNOWN"
- `last_seen` (DATETIME, Nullable)
- `timestamp` (DATETIME, Default: UTC Now)

### Table: `system_config`
Key-value store for persisted system configurations and thresholds across reboots.
- `id` (INTEGER, Primary Key, Auto-increment)
- `key` (VARCHAR(50), Unique, Indexed, Not Null)
- `value` (VARCHAR(200), Not Null)
- `updated_at` (DATETIME, Default: UTC Now)

---

## 2. Data Retention Policy
- Raw `sensor_readings` can generate hundreds of records per minute. The system provides a configurable data retention window (default 30 days) via `POST /api/v1/settings/cleanup?retention_days=N`.
- `obstacle_events`, `warning_events`, `traffic_signal_events`, and `system_config` are retained permanently for analytical and audit integrity.
